IMPORTANT
---------
* This is a TEMPLATE / pseudocode skeleton — NOT production-ready for all
  ToolRoom / iGrind software generations (RN versions).
* Parameter IDs, wizard field names, and scripting APIs differ by release.
  You MUST adapt IDs and calls to YOUR ToolRoom release using ANCA documentation
  and ANCA Club sample scripts.
* ANCA TGX Studio does NOT write proprietary .TOM binaries. ToolRoom creates
  the .TOM. Always verify the result in CIM3D before grinding on a TGX.
* Confirm TGX software generation / post options with ANCA or your machine docs.

Safe workflow
-------------
  Studio params  →  ToolRoom (manual iGrind wizard OR adapted script)
                 →  .TOM saved by ToolRoom
                 →  CIM3D verify
                 →  TGX grind

Studio JSON handoff schema
--------------------------
Exported files use:
  schema:          "toolroomHandoff"
  schemaVersion:   1

Top-level keys:
  disclaimer, generatedAt, toolType ("endmill" | "drill"), designId,
  fields, mapping, notes

`fields` — flat map of studio JSON field names (use these keys when reading
the downloaded handoff JSON):

  Common / both types:
    toolType, name, diameter, fluteCount, overallLength, fluteLength,
    shankDiameter, shankLength, coating, material

  Solid endmill only:
    helixAngle, cornerRadius, neckDiameter (nullable), neckLength (nullable)

  Drill only:
    pointAngle, webThinningNote

Units in the studio are millimetres and degrees as labeled in the UI.
`mapping` rows also carry human ToolRoom-style labels for manual entry.
